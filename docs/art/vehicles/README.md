# Vehicle turnaround sheets

Orthographic reference sheets (front, right side, back and top on one ground line) for
modelling robotaxis that have no downloadable source model. They were generated with
Codex image generation at real-world proportions, in the game's drawing style.

- `zoox.png`: Zoox-style bidirectional robotaxi, about 3.6 × 1.9 × 1.9 m. The ends are identical.
- `apollo.png`: Baidu Apollo RT6-style robotaxi, about 4.6 × 1.85 × 1.65 m.

These are references, not assets. The sheets are drawn, so expect small inconsistencies
between views. Where views disagree, the front wins for widths and the side for lengths and heights.
