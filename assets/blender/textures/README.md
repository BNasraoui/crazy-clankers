# Tech Bro face decal

`techbro-face-decal.png` is a committed transparent art source generated with the **built-in imagegen tool** on 2026-10-01. It is consumed by `techbro_head.py`, which inverse-samples it into a cylindrical UV atlas, flattens the eyebrow pigment and neutral whites, composites it onto flat skin albedo, and embeds the resulting atlas in the GLB. It is not a rendered head texture, a front camera projection, or a substitute for the head geometry. Rebuilds use this fixed file and require no image service.

Inputs: `assets/blender/reviews/reference-head.png` (an enlarged crop of `docs/art/cast.jpg`) and `docs/art/portraits.jpg`. The tool's original output remains in the resident generated-images directory; this copy is the project source. Transparent alpha is retained.
